# Titik Jeda - Mental Health Web Application

## Fitur Utama
*   **Dashboard User**: Akses fitur meditasi dan edukasi bagi pengguna.
*   **Skrining DASS-21**: Tes interaktif dengan kalkulasi skor otomatis untuk indikator Depresi, Kecemasan, dan Stres.
*   **Sistem Rekomendasi**: Menyajikan audio meditasi berdasarkan hasil skor tertinggi dari tes DASS-21.
*   **Media Streaming**: Pemutar audio dan video native HTML5 yang terintegrasi dengan backend.
*   **Dashboard Admin (CMS)**: Manajemen data konten (CRUD) dan fitur unggah file audio/video baru dengan preview instan.

## Tech Stack
*   **Frontend**: React.js (Vite) + Tailwind CSS
*   **Backend**: Node.js + Express.js
*   **Database**: MySQL 8.0
*   **Containerization**: Docker & Docker Compose

## Prasyarat Sistem
*   Docker Desktop (termasuk Docker Compose)
*   Web Browser terbaru
